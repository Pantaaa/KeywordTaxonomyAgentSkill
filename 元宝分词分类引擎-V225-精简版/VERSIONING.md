## 自动升级流程（每次迭代后执行，单版本替换）

**必须从 D 盘根目录或外部目录运行**（避免 Windows 占用当前技能目录）：

```bash
cd /d D:\
python "D:\元宝分词分类引擎-V188\upgrade_skill.py" --old V169 --new V170 --ws
```

升级工具自动完成：
1. 复制 `D:\元宝分词分类引擎-V188` → `D:\元宝分词分类引擎-V188`
2. 重命名 `classify_engine_v188.py` → `classify_engine_v188.py`

6. **【替换】删除旧版本目录（D盘 + 工作区），始终只保留 1 个版本**

> 如需保留旧版回溯，加 `--keep-old` 参数（默认删除）。
